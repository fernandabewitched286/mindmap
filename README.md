## ✨ What Can You Do With mindmap?

### 🌱 Create Your First Mind Map

Opening mindmap presents you with a blank canvas and a single central node labeled "Central Topic." That's your starting point. Click on it to select it, then start typing to rename it to whatever you're thinking about — a project name, a problem you're solving, a book you're reading, anything.

### ➕ Add Ideas (Nodes)

- **Keyboard shortcut:** Press `Tab` while a node is selected to add a child idea (a branch off the current node).
- **Keyboard shortcut:** Press `Enter` while a node is selected to add a sibling idea (a branch off the same parent as the current node).
- **Mouse alternative:** Right-click on any empty space near a node to see a context menu with "Add Child" and "Add Sibling" options.

### 🎨 Organize and Edit

- **Rename:** Double-click any node to edit its text.
- **Delete:** Select a node and press `Delete` or `Backspace` on your keyboard.
- **Move:** Click and drag any node to reposition it freely on the canvas.

### 🖱️ Navigate the Canvas

- **Pan:** Click and drag on empty canvas space to move around your map.
- **Zoom:** Use your mouse wheel or trackpad pinch gesture to zoom in and out.
- **Fit to screen:** Look for a "Fit" button (usually in a corner) to quickly zoom out and see your entire map at once.

### 🧭 Watch the Magic: Auto-Layout

Here's one of the coolest features: when you add several child nodes, they don't just pile up randomly. mindmap automatically rearranges them in a tidy, balanced tree layout so your map always looks organized and easy to read. No manual positioning needed — but you can always drag nodes yourself to customize the arrangement.

### 💾 One-Click Persistence

Worried about losing your work? Don't be. Your mind map is saved automatically as you work, right in your browser's local storage. That means:

- If you close the tab or shut down your computer, your map will still be there when you come back.
- You don't need to click "Save" — it's always saving.
- You can clear it anytime by using a "New Map" or "Reset" option if available.

## 🔧 Troubleshooting

### 🚫 The page won't open when I double-click the file.

**Solution:** Right-click the file, select "Open with," and choose your web browser (Chrome, Edge, Firefox, etc.). If that still doesn't work, try dragging the file into an already-open browser window.

### 🔄 My mind map disappeared after I closed the browser.

**Solution:** Check that you're using the same browser and computer as before. The map is stored locally in that specific browser. If you use a private/incognito window, data won't be saved.

### 💾 I want to back up my mind map.

**Solution:** Look for an "Export" or "Save Copy" option in the interface. If none exists, the simplest backup is to keep the downloaded HTML file itself — your data is embedded within it (though some versions store separately). When in doubt, export as an image if the option is available.
